# Bubble Tea Shop System

A full-stack shop management and ordering system for a bubble tea shop.

## Overview
Shop staff manage recipes, inventory, and sales; customers order drinks.
Inventory is the core: selling a drink auto-deducts its ingredients, and stock
is tracked as a ledger of movements.

## Tech Stack
| Layer | Choice |
|---|---|
| Backend | Python + FastAPI |
| Database | PostgreSQL |
| Frontend | React + Ant Design |
| Auth | Username / password + JWT |
